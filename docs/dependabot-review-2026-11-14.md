# Bloomwood Dependabot review — 14 November 2026

At commit f4c44aa, GitHub returned 69 open alerts against the root package-lock.json: 1 critical, 29 high, 30 medium, 9 low. npm audit independently reported 42 affected package entries (including dependent parents). These counts use different units. This is a source and lockfile assessment, not evidence of exploitation or a live penetration test.

## Recommended changes

1. Prioritize a coordinated Astro 7 upgrade from 6.4.8 with compatible Cloudflare, MDX and React integrations. All eight Astro advisories must be outside their affected ranges. Upgrade both Sharp paths (Astro and Miniflare) to patched releases. The critical advisory requires untrusted AVIF processing by native Sharp/libheif. The deployed adapter uses Cloudflare Images; no application getImage call, astro:assets import, or public Sharp upload path was identified. Build-time processing and future content changes still warrant the upgrade. The Node adapter finding is not a match for this Worker. No custom Astro base or View Transitions usage was found; trusted repository MDX and React islands do exist.
2. In a separate, lower-risk dependency refresh, update RSS, Vite, devalue and eligible lockfile transitives. RSS items come from repository blog frontmatter; the feed is generated at build time. Astro and its React integration share devalue; package presence does not establish arbitrary public input to its affected methods. Keep dev and preview servers private.
3. Update Wrangler/Miniflare to resolve the nested Undici and Sharp versions. Undici here is reached through the local Worker emulator; this does not establish that the live Worker uses that implementation for fetch. Refresh the CSS, SVG, YAML, TOML, browser targeting and source-map toolchain through compatible parents. Verify every installed copy of each flagged package. Do not assume a forced override across majors is compatible.
4. Validate with a clean npm ci, security/CRM/UI tests and npm run cf:check. Smoke-test callback/login, public pages, RSS, image delivery and hydrated navigation in a Worker preview. Re-run npm audit and check GitHub alerts after merging. A lockfile update alone does not patch the deployed Worker.
